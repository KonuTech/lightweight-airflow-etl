ordering (D-13/D-14/D-15) or the generator contract (D-11) before broader fixture coverage is built
on top of a wrong foundation.

## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Untrusted CSV file content → validate.py/normalize.py | Every value in every row is attacker-influenced (a dropped file this project's own generator produces, but structurally the same trust boundary a real upstream feed would present) |
| Untrusted CSV file content → source.py's structural reject path | A malformed header/dialect is the first line of defense before any row content is trusted |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-05 | Tampering | `validate.py`'s type-check dispatch (`convert_value`) | high | mitigate | Every type conversion uses strict, exact parsing (`Decimal`, `strptime`, `int()`) inside `try/except`, never `eval`/format-guessing/`float()` — a malformed value is always rejected via `error_code`, never silently coerced |
| T-03-06 | Denial of Service | `csv.field_size_limit` left at Python's unstated default | medium | mitigate | `source.py` sets `csv.field_size_limit(1_048_576)` explicitly at module scope (RESEARCH.md Pattern 6), so an unterminated-quote runaway field fails predictably rather than inheriting whatever the interpreter's default happens to be |
| T-03-07 | Repudiation | `error_message` text could omit which column/value actually failed | low | mitigate | `check_row`'s `error_message` always names the specific column (`f"{col.name!r} ..."`), per this plan's prohibitions list |
| T-03-08 | Denial of Service | A crafted row causing an unhandled exception inside `check_row`/`convert_value` could crash the whole generator mid-file | medium | mitigate | Every type-check path returns `(value, error_code)` tuples rather than raising; the only exceptions `process_chunks()` lets propagate are whole-file structural rejects raised once at generator start, per this plan's prohibitions list |
