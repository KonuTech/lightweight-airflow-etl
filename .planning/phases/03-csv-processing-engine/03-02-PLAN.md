## Trust Boundaries

| Boundary | Description |

| Untrusted CSV bytes → detection layer | `detect_dialect`/`detect_encoding`/`detect_header` are the first code to touch attacker-controlled file content |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|

</threat_model>
