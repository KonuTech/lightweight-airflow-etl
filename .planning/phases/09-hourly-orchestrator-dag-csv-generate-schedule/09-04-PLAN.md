<interfaces>
Reference request/response shapes (all already proven working in this exact environment by
docs/airflow-dag.md's existing csv_ingest DAG-03/DAG-05 evidence -- read that file's full content
before writing any new evidence):

- Auth: POST http://localhost:8080/auth/token, body {"username": "admin", "password": "admin"},
  response field .access_token -- identical flow scripts/trigger_dag.sh already uses (not modified
  by this plan, read only as a reference).
- Trigger: POST http://localhost:8080/api/v2/dags/{dag_id}/dagRuns, body {"logical_date": null}
  (logical_date is a required-but-nullable field on Airflow 3.3.1's TriggerDAGRunPostBody --
  omitting it entirely returns HTTP 422), response field .dag_run_id.
- Poll one task instance: GET http://localhost:8080/api/v2/dags/{dag_id}/dagRuns/{run_id}/taskInstances/{task_id},
  response fields .state and (when deferred) .trigger.classpath.
- Poll one DagRun to a terminal state: GET http://localhost:8080/api/v2/dags/{dag_id}/dagRuns/{run_id},
  response field .state.
- Wait for completion (streaming): GET http://localhost:8080/api/v2/dags/{dag_id}/dagRuns/{run_id}/wait?result={task_id}&interval={seconds},
  header Accept: application/x-ndjson -- `interval` has no default in this environment's
  openapi.json and must be passed explicitly (already recorded as an API note in
  docs/airflow-dag.md).
- Pause/unpause: PATCH http://localhost:8080/api/v2/dags/{dag_id}, body {"is_paused": true|false}.
</interfaces>
